Avery Murray Portfolio Website

Files:
- index.html
- styles.css
- script.js
- assets/

To preview locally:
1. Open index.html directly in a browser, or
2. Run a simple local web server in this folder, e.g.:
   python -m http.server 8000
   then visit http://localhost:8000

The site is fully static and responsive. No build step or external dependencies are required.
